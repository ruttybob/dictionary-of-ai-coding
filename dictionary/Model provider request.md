Один цикл обмена от [обвязки](./Harness.md) к [провайдеру моделей](./Model%20provider.md). Обвязка отправляет текущий [контекст](./Context.md); провайдер возвращает один ответ ([вызов инструмента](./Tool%20call.md) или финальный ответ). Одно сообщение пользователя может породить много запросов к провайдеру моделей, если [агент](./Agent.md) вызывает [инструменты](./Tool.md) — каждый [результат инструмента](./Tool%20result.md) запускает новый запрос.

Каждый запрос несёт в себе всё: [системный промпт](./System%20prompt.md), всю беседу до текущего момента, каждый результат инструмента. [Модель](./Model.md) [без сохранения состояния](./Stateless.md), поэтому провайдер ничего не хранит между запросами — запрос сорок повторно отправляет то, что отправил запрос тридцать девять, плюс ещё один результат инструмента. [Префиксный кэш](./Prefix%20cache.md) существует, чтобы сделать такое повторение недорогим.

Запрос — это также единица биллинга. [Входные токены](./Input%20tokens.md), [выходные токены](./Output%20tokens.md) и скидки за кэш — всё это считается по запросам, поэтому невинно выглядящий вопрос может стоить удивительно много: стоимость пропорциональна не вашему сообщению, а количеству запросов, умноженному на размер контекста, который несёт каждый из них.

Стоит различать запрос и [ход](./Turn.md). Ход — это один обмен с вами, и один ход — «почини падающий тест» — разворачивается как цепочка запросов:

| Запрос | Модель возвращает                                | Затем обвязка                                         |
| ------ | ------------------------------------------------ | ----------------------------------------------------- |
| 1      | Вызов инструмента: запустить тесты               | Запускает их, добавляет вывод с ошибками              |
| 2      | Вызов инструмента: прочитать тестовый файл       | Добавляет содержимое файла                            |
| 3      | Вызов инструмента: прочитать файл исходного кода | Добавляет содержимое файла                            |
| 4      | Вызов инструмента: изменить файл исходного кода  | Применяет правку, добавляет результат                 |
| 5      | Вызов инструмента: запустить тесты снова         | Запускает их, добавляет вывод об успешном прохождении |
| 6      | Финальный ответ: «исправлено, тесты проходят»    | Показывает его вам                                    |

Шесть запросов на один ход — каждый заново отправляет весь контекст. Когда задаётесь вопросом, куда ушли [токены](./Token.md), считайте запросы, а не ходы.

_Пример:_

«Один вопрос сожёг сорок тысяч токенов?»

«Посмотрите на вызовы инструментов — двенадцать grep, восемь read, четыре правки. Каждый результат инструмента порождает новый запрос к провайдеру моделей, и весь префикс [сессии](./Session.md) отправляется заново каждый раз.»
