# Wiki site — словарь AI-кодинга как локальная вики

## Problem Statement

Текущий сайт — 3D-граф на React + WebGL (`site/src/scene/`). Требование изменилось: читатель скачивает репозиторий, запускает сайт локально одной командой и читает словарь как обычную вики. 3D-сцена этому мешает: тяжёлые зависимости (`three`, `@react-three/*`, `d3-force-3d`, `gsap`), долгая установка, навигация построена вокруг эффекта, а не чтения.

## Solution

Заменить 3D-фронтенд обычным wiki-ридером на существующем стеке (Vite + React + marked). Данные, пайплайн и валидация не меняются: `internal/generate-site-data.ts` → `site/src/data.json`, freshness-проверка в CI остаётся. UI: сайдбар с содержанием по секциям Curriculum, страница термина (описание, тело, связанные термины, prev/next), поиск, хеш-роутинг. Локальный запуск: `npm install && npm run dev`.

## User Stories

1. Как читатель, я хочу `npm install && npm run dev` и сразу читать словарь, чтобы не разбираться с установкой.
2. Как читатель, я хочу содержание слева со всеми секциями и терминами, чтобы видеть объём и структуру словаря.
3. Как читатель, я хочу страницу термина с заголовком, секцией, описанием и телом, чтобы читать статью как в вики.
4. Как читатель, я хочу кликабельные перекрёстные ссылки внутри статей, чтобы переходить по смыслу.
5. Как читатель, я хочу поиск по названию и тексту статей, чтобы находить термин по русской формулировке.
6. Как читатель, я хочу prev/next по порядку Curriculum, чтобы прочитать словарь от начала до конца.
7. Как читатель, я хочу список связанных терминов на странице, чтобы видеть контекст понятия.
8. Как читатель, я хочу диплинк вида `#Term`, чтобы делиться и закладывать термины.
9. Как читатель, я хочу главную страницу с обзором словаря, чтобы начать без случайного термина.
10. Как читатель с телефона, я хочу читаемую вёрстку без горизонтального скролла.
11. Как читатель, я хочу закрыть статью по Esc и вернуться на главную.

## Non-goals

- 3D-визуализация: остаётся в истории git и на ветке `graph-site`.
- Поисковый индекс и ранжирование: подстрочного поиска достаточно для 71 термина.
- Серверная часть: статический билд, без бэкенда.

## Testing Decisions

Visitor-level seam'ы без WebGL: `html[data-ready='true']`, `#search` / `#results .result`, `#article` с `data-term`, `#article-title`, `#article-body`, `.nav-btn` с aria-label. e2e гоняются против собранного `dist/` (`npm run build && npm run preview`), как раньше.
