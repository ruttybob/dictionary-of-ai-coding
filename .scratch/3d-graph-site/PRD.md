# 3D Graph Site — словарь AI-кодинга как интерактивный 3D-глобус

## Problem Statement

Текущий граф-сайт (`ru-graph-site`, vanilla HTML + 2D D3-force SVG) работает, но визуально плоский и спроектирован под ограничение «лёгкость + GitHub Pages». Посетитель получает статичную 2D-карту связей терминов, без ощущения пространства, глубины и кинематики. Нужна совершенно иная подача того же двуязычного словаря (русские определения, английские headword-ы): **3D-глобус из светящихся стеклянных сфер**, по которому камера перелетает между терминами в стиле Google Earth, с bloom-свечением, орбитальной кинематикой и pedagogical-обходом по Curriculum. Ограничение лёгкости/Pages снимается — допустим полноценный билд (Vite + React + WebGL).

## Solution

Полноценная React + WebGL-сцена (Vite, react-three-fiber, @react-three/postprocessing): единый 3D-граф всех терминов словаря, где узлы — стеклянные сферы, окрашенные по секции Curriculum, размером ∝ degree (связности). Раскладка — свободная force-симуляция (d3-force-3d) со слабой радиальной силой, так что весь граф читается как рыхлая сфера, а секции сами кластеризуются в органические «континенты» за счёт плотности внутренних связей. Иерархия и фокус выражаются **прозрачностью** (α) плюс **селективным bloom** (горят только lit-узлы, не глобальная заливка). Любое переключение между узлами (клик, prev/next, поиск, cross-link, hash) запускает орбитальную дугу камеры над глобусом. Тема только тёмная (OLED-чёрный) — bloom требует тёмного холста. Тот же источник данных (`site/data.json`), та же двуязычная модель, та же атрибуция.

## Implementation Decisions

- **Стек:** Vite + React + TypeScript. Рендеринг — `@react-three/fiber` (React-рейндерер для three.js) + `@react-three/postprocessing` (эффект **Bloom**, селективный по порогу яркости). Текст в 3D — `troika-three-text`. Камера-анимация — `gsap`. Тело определения — `marked` (переиспользуется). Сборка → статический `dist/`.
- **Единый граф (Reading A):** один 3D-граф на все 69 узлов; секции НЕ изолируются в подграфы. Цвет секции — атрибут узла; «фокус секции» через легенду затемняет остальное, но кросс-рёбра остаются видимыми как мосты. Обоснование: 352 из 526 рёбер — кросс-секционные (67%); изоляция отрезала бы суть графа.
- **Раскладка:** `d3-force-3d` (link + charge + center + слабая `forceRadial` к целевому радиусу). Никакого навязанного `forceCluster` — секции кластеризуются органически за счёт плотности link-связей (174 внутри-секционных рёбер). Результат — рыхлая сфера с цветными «континентами», отражающая реальную топологию.
- **Узлы:** sphere-меши, материал `MeshPhysicalMaterial` (glass/transmission), цвет = цвет секции, радиус ∝ √degree. Хабы Agent(52)/Session(47)/Model(43) — крупнейшие.
- **Акцент через прозрачность + селективный bloom:** α-иерархия (выбранный 1.0, соседи ≈0.9, прочие ≈0.15, фокус секции, не-совпадения поиска ≈0.1). Bloom — luminance-пороговый, горят только lit-узлы; НЕ глобальная заливка (anti-AI-slop). Bloom reinforce α, а не конкурирует.
- **Лейблы (адаптивно):** постоянно — у выбранного узла, у top-degree хаба каждой секции (7), у совпадений поиска во время ввода; по hover (десктоп)/tap (мобайл) — у остальных; плюс fade по дистанции камеры. troika-three-text, billboard; лейблы в bloom не участвуют.
- **Камера:** `OrbitControls` (орбита/зум руками) + `gsap` для орбитальной дуги при переключении узла (spline-путь вокруг центра, глобус фиксирован, летит камера). Очень медленный idle auto-rotate через `autoRotate`, пауза на pointer/touch, возобновление после таймаута (~4с).
- **Prev/Next = Curriculum-обход:** шагает по каноническому порядку `internal/Curriculum.md` (плоский список ID в поле `order`). Next всегда активен. Триггерит ту же дугу камеры, что и клик.
- **Панель:** справа glass-панель (десктоп, ~400px, выезжает, скроллящееся тело); на мобайле — bottom-sheet. Шапка: prev/next + заголовок. Тело: marked-рендер с перехватом `./X.md` → выбор узла X + дуга + hash.
- **Поиск:** клиентский фильтр по label + description + body; несовпадения → α≈0.1, совпадения горят; мягкий recenter камеры на центроид совпадений; список результатов.
- **Легенда:** 7 чипов секций (top-left), кликабельны → фокус секции (toggle).
- **Тема:** только тёмная. Переключатель тем и учёт `prefers-color-scheme` убираются.
- **Диплинки:** hash URL = имя термина → выбор узла + прилёт камеры при загрузке.
- **Данные:** расширяется существующий генератор — `site/data.json` получает поле `order: string[]` (ID узлов в порядке Curriculum). Существующие поля (sections, nodes[id,label,section,description,body], edges[source,target]) без изменений.
- **Производительность / a11y:** адаптивный DPR и разрешение bloom (ниже на мобайле/weak GPU); `prefers-reduced-motion` → auto-rotate off, bloom off, мгновенные срезы камеры; keyboard (focus-visible, Esc).
- **Деплой:** статический артефакт из `dist/`; размещение на любом стат. хостинге (Pages/Netlify/Vercel). Цель «не Pages» означает снятие ограничения лёгкости, а не отказ от статичного вывода.
- **Связь с `ru-graph-site`:** эта работа перестраивает реализацию `site/` и обращает несколько решений 2D-версии (тёмная-only, WebGL против SVG, тяжёлый билд против статического HTML, Google-Earth камера). 2D-PRD в `.scratch/ru-graph-site/PRD.md` остаётся исторической записью; `Status:` там следует перевести в терминальное состояние при завершении 3D-перестройки.

## Testing Decisions

- **Хороший тест** проверяет только внешнее поведение посетителя, никогда — внутренности react-three-fiber / three.js / WebGPU-сцены. Внутренности (силы, материалы, шейдеры) тест-покрытия не имеют.
- **Единственный visitor-шов:** один Playwright-файл (`tests/site.spec.ts`, переписывается под новый контракт). Сценарии: (a) сцена смонтирована — `<canvas>` присутствует и корень получил `data-ready` после укладки графа; (b) поиск затемляет не-совпадения и подсвечивает совпадения; (c) клик по узлу открывает панель с русским определением (`data-term`); (d) cross-link в определении перелетает к целевому термину; (e) prev/next перемещают по Curriculum-порядку; (f) hash-диплинк открывает термин на загрузке; (g) под `prefers-reduced-motion` auto-rotate выключен.
- **WebGL-контракт (проблема счёта узлов):** граф рендерится в `<canvas>`, DOM-узлов для `.node`-каунта больше нет. Число узлов проверяется на **слое данных** (`site/data.json` содержит N узлов — читается в module-scope теста, как сегодня). Корректность рендеринга доказывается **косвенно** через `data-ready` + взаимодействия: если клик по известному узлу открывает его панель, значит граф живой. Тест не лезет в R3F/three-инстансы.
- **Шов `data-ready`:** приложение выставляет `data-ready` на document root, когда сцена смонтирована и force-симуляция выдала первые позиции. Единственная test-only точка контакта с внутренностями.
- **Переиспользуемый шов:** CI-паттерн «сгенерируй → git diff» (рядом с `readme-fresh.yml`), расширенный на `site/data.json` + новое поле `order` + `npm run build` (падает, если dist дрейфит или `order` невалиден).
- **Убираются:** тест переключателя тем и тест `prefers-color-scheme: light` (тема теперь только тёмная).
- Юнит-тестов на 3D-рендер нет; visitor-смок — это и есть шов.

## Out of Scope

- Светлая тема (bloom требует тьмы; продукт теперь кинематографичный исследователь, не справочная таблица).
- Строгий географический глобус с навязанными секционными «континентами» (ценой потери граф-правды — выбрана органическая кластеризация).
- Редактирование записей через сайт (только чтение).
- Любой серверный компонент / база / авторизация / аналитика.
- Переключатель языков (только русский; английский есть апстрим).
- Индивидуальные 3D-модели/иконки на узел (все узлы — сферы с цветом секции).
- Звук/Audio.
- Перевод README-интро (отдельная задача).
- Перевод/правка контента словаря (уже сделано).

## Further Notes

- **Domain-словарь:** headword-ы остаются английскими (лейблы узлов), определения — русские (тело панели). Соответствует двуязычной модели проекта.
- **Атрибуция:** оригинал — mattpocock/dictionary-of-ai-coding (Matt Pocock); сохранять видимый кредит.
- **Данные прототипа:** 69 узлов, 526 рёбер (174 внутри-секционных, 352 кросс); 7 секций размерами 16/11/10/9/9/8/6; хабы Agent(52), Session(47), Model(43).
- **Supersedes `ru-graph-site` (2D):** тот же продукт и источник данных, но обращены решения «тёмная-only против toggle», «WebGL против SVG», «тяжёлый билд против статического HTML», добавлены Google-Earth камера и Curriculum-обход. По завершении 2D-PRD переводится в `Status: cancelled`/`done` со ссылкой на эту перестройку.
- **Anti-AI-slop-дисциплина** (из `~/.design` skills huashu-design, high-end-visual-design): градиентный bloom-свечение как глобальная заливка banned — только селективный; emoji-иконки banned; Inter banned; «colored-orb» узлы оправданы как буквальное Ethereal Glass, а не как слоп.
